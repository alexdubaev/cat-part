# Локальный стенд CatPart

Открыть [витрину](http://127.0.0.1:8095/) и [админку](http://127.0.0.1:8095/admin/). Постоянная установка: `D:/codex/cat-part/admin-stand`. Сгенерированные локальные сотрудники находятся только в `local-dev/admin-runtime/private/accounts.json` внутри установки; этот файл не публиковать. Реальные сайты и письма не затрагиваются.

Из постоянной установки: `python tools/admin-dev.py start`, `status`, `stop`. Команда stop проверяет принадлежность процесса; общий MariaDB и сайт на 8080 не останавливаются. PHP/MariaDB берутся из `D:/codex/cat-part/cat-part/local-dev/bin`, старые изображения разрешены только для чтения. После перезагрузки сначала нужен доступный локальный MariaDB на 3307, затем start.

| Раздел | Действия и публичный результат |
|---|---|
| Каталог | Создать/изменить товар, категорию, бренд, характеристику; главное фото, галерея/alt/подпись, дополнительные категории, наличие да/нет, цена/валюта/по запросу. Витрина, поиск и корзина читают тот же товар. |
| Импорт | CSV/XLSX: загрузить → выбрать колонки → preview/ошибки строк → явно подтвердить apply → сохранить отчёт. Файл приватен. Повторный apply не дублирует результат; неуказанные колонки сохраняются. Лимиты и продолжение показаны в форме. |
| Содержимое | Статьи: заголовок/slug/анонс/автор/обложка/SEO, визуальный редактор, draft/preview/publish/scheduled/archive, история/восстановление. Главная и страницы — управляемые поля и блоки. |
| Настройки | Контакты, branding, меню/footer, формы, карта, аналитика/подтверждения, отправитель/получатели уведомлений. Очистить карту — блок исчезнет. Local/admin не подключают аналитику. |
| Заказы | Снимок исходных позиций и условий, контакты/комментарий, статус, ответственный, внутренняя заметка и новое предложение с историей. Менеджер подтверждает условия; это запрос, а не оплаченная продажа. |
| Обращения | Сохранённые формы с источником/сообщением, статусом/ответственным и историей. Номер показывается после commit, даже при ошибке почты. |
| Обслуживание | Состояния очереди, безопасный retry; локальный worker пишет private capture. Нет обещания inbox delivery. |
| Сотрудники | Нативные пользователи и группы: администратор управляет; редактор каталогом/импортом/контентом; менеджер заказами/обращениями/сводкой; reader только читает контент. Access и modify проверяются отдельно. |

При смене slug требуется подтверждение; старый URL получает прямой 301 на текущий. Связанные записи архивировать; ошибки связи/цикла/занятого slug сохраняют прежние данные. Для проверки изменений используйте локальную витрину, не боевые формы.

Нативные оплаты, покупатели, складские резервы, мультисклад, рассылки, 1С и прочие неинтегрированные инструменты выключены; это отдельные будущие модули. Публичная загрузка файлов посетителями не включена.

Проверка установки: `python tools/test-admin-integration.py --package PATH_TO_ZIP` из установленного пакета. Требуются реальная MariaDB и cached Node Playwright для browser group; отсутствие зависимости даёт FAIL, не синтаксический PASS. Группы: `--group foundation|catalog|content|requests|browser|shipping|package`. Фактические результаты передаются в HANDOFF. Хостинг, реальная доставка и рабочие сотрудники на хостинге: **NOT RUN**, по запрету владельца менять действующие сайты.
