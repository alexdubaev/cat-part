# Устройство единой админки

Витрина CatPart и OpenCart 4.1.0.4 используют одну изолированную БД. Товары, категории, характеристики, связи, изображения и статьи остаются в прежних таблицах и сохраняют идентификаторы. Расширение `extension/catpart` добавляет метаданные, содержимое, историю, редиректы, аудит, запросы и очередь уведомлений. Повторная миграция аддитивна и не очищает неизвестные записи.

Нативные вход, сессия, группы сотрудников, оболочка и CKEditor используются через extension hooks. Неинтегрированные нативные каталог, покупатели, продажи, маркетинг и отчёты закрыты на сервере. Заказ-запрос пишется транзакцией в `oc_order`, позиции/историю и связанные `cp_order`/idempotency/outbox. Commerce lifecycle OpenCart не вызывается: нет списания запасов, платежей, регистрации покупателя. Неизвестная цена сохраняется nullable в неизменяемом снимке. Смешанные валюты не суммируются через придуманный курс.

Витрина читает те же товары и централизованные настройки; редиректы ведут сразу на текущий slug. HTML очищается DOM allowlist на сервере. Native admin POST декодируется один раз перед проверкой; HTML экранируется при выводе. Public input не проходит native decode. Даты новых записей UTC; старые даты статей Moscow конвертируются один раз с сохранением оригинала в marker.

Runtime приватен: сгенерированные сотрудники, native/public config, DB password, сессии, captures, imports/backups/logs отделены от исходников. Процесс слушает только 127.0.0.1. Mailer принудительно capture; успешный capture не означает доставку адресату. Старые `/upload` читаются из разрешённого source media path; новые `/media` пишутся только в свой стенд.

Пакет устанавливает собственную копию всех app/extension/router/assets/defaults. Нативное ядро извлекается из закреплённого ZIP в runtime и не изменяется расширением. Стенд переживает удаление временного Git worktree; внешними остаются ready PHP/MariaDB и read-only изображения источника.

Решения и причины: ADR-001..004. Операции — `admin-guide.md`, перенос/backup/rollback — `admin-migration.md`, зависимости — `admin-reuse.md`.

## Карта единого источника

| Сущность | Источник | Редактор | Потребители |
|---|---|---|---|
| Товары | products + product_images/cross/attr_values/compat и cp_product metadata | Каталог CatPart | карточка, поиск, каталог, подборки, корзина, sitemap |
| Категории | categories, исходная path и cp_category metadata | Категории CatPart | дерево, страницы, родительские выборки, меню, sitemap |
| Бренды/характеристики | brands/attributes + cp metadata | Каталог CatPart | карточка, связи, поиск, импорт |
| Статьи | blog_posts + cp_article_revision/link | Содержимое → Статьи | главная, статьи, связанные блоки, SEO, sitemap |
| Страницы/главная/меню/формы | cp_content/cp_settings | обычные формы содержимого/блоков | существующие шаблоны CatPart |
| Контакты/карта/бренд/аналитика | cp_settings | Настройки сайта напрямую | все публичные представления и структурированные данные |
| Заказы | oc_order/product/history + cp_order meta | Заказы CatPart | подтверждение, история, менеджерские экраны/отчёты |
| Обращения | cp_lead/history | Обратная связь | все формы, менеджерские экраны |
| Уведомления | cp_outbox | Обслуживание + карточки | локальный worker/capture, ошибки/повтор |
| Доступ/аудит | native oc_user/group + cp_audit | пользователи и права | каждый admin route, preview/download, журнал |

Таблица была подготовлена до разработки: сохранена в plan commit `3f2f046` до первого программного commit `002bb72`; здесь повторена для владельца и следующего исполнителя. Исходные ID каталога сохраняются, отдельного изменяемого каталога OpenCart нет.
