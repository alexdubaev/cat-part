# ADR-004: Выборочное повторное использование зависимостей

## Контекст

Для OpenCart доступны совместимые модули CMTEH, но полный модуль включает настройки другой витрины и складские правила, неприменимые CatPart.

## Решение

Проверять транзитивные зависимости и адаптировать только нужные совместимые библиотеки/редактор по отдельным файлам или модулям. Фиксировать происхождение, версию и лицензии реально используемого кода; устанавливать только проверенные зависимости.

## Почему

Отвергнута установка целого модуля: она принесла бы чужие настройки, витрину и складскую семантику. Отвергнуто подключение непроверенных транзитивных библиотек: совместимость и лицензионное происхождение остались бы неясными.

## Последствия

Пакет содержит только фактически используемый код и перечисляет его зависимости и лицензии. Интеграция должна сохранять ограничения CatPart и не добавлять складской учёт.
