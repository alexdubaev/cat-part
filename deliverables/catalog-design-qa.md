# Каталог: визуальная приёмка 2026-11-12

Референс владельца: компактная левая панель, категории списком без иконок, товары в основной области. Бренд один, отдельного выбора бренда нет.

Реализовано в существующем PHP MVC: три колонки товаров на десктопе, две на узком экране; текстовое дерево с независимым раскрытием стрелкой и переходом по названию. Подкатегории не отодвигают товары вниз. Действующие поиск, наличие, сортировка и номер страницы отражаются в URL. На мобильном фильтры раскрываются над товарами.

В браузере проверены общий каталог (7134 товара), Гидравлика (465 товаров) и экран 390×844: фильтры доступны, карточки и длинные названия помещаются, горизонтальной прокрутки нет. Товарные изображения используют существующие WebP, новые библиотеки и растровые ресурсы не добавлены. Для фильтра «Тип запчасти» нет самостоятельного поля данных — тип выбирается через дерево категорий.

Автоматическая проверка: `tools/test-catalog-sidebar.cjs`. Связанные проверки главной и оформления заказа пройдены. Реальные письма и изменения production БД не требовались.
